# Week Ahead

Look across the whole coming week so nothing sneaks up: events that still need organising, things
to book now rather than on the day, helper gaps, loans falling due, news about to expire, and help
requests with a deadline in the window. This is the wider net the daily brief deliberately leaves
out — the brief handles today, the week-ahead is the planning view. Fires weekly at the day and
time the community set (a recurring task), and runs on ask any time.

**The schedule is your approval** for this routine post and only this one (ground rule 4). A draft
announcement, a named nudge, or anything else the run turns up still comes back for a go-ahead.

## Gather

Query Notion for the next seven days and a bit beyond (`notion-schema.md`). Work every date
boundary out with code (ground rule 13).

- **The week's events**: Events `Upcoming` with `Date` in the coming window. Also look a little
  further for anything that needs starting now to happen later.
- **What would stop each one happening**: no `Host`, `Helpers Short` above 0, `Bringing` still
  thin, a venue unbooked, `Capacity` nearly met, or nobody's announced it yet. Notion doesn't
  record whether something's been announced, so check memory (`events-and-rsvp.md`). Give it enough
  lead time to actually act; flagging a booking the day before is useless.
- **Loans due back this week**: Loans `Active` with `Due Date` inside the window, so a return is a
  heads-up rather than a chase. Plus anything already `Overdue` that the daily brief hasn't got
  moving.
- **News about to expire**: News `Published` or `Pinned` with `Expires On` in the window. Either
  it needs renewing or it needs `Archived` — say which you think it is.
- **Pinned news**: the standing items. Worth one quiet restatement in a planning post, because new
  neighbours never scrolled back far enough to see them.
- **Help requests with a deadline**: Help Requests still `Open` with `Needed By` in the window.
  These are the ones where "next week" quietly becomes "too late".
- **What memory knows is coming**: the annual thing, the seasonal clear-up, the neighbour who
  always needs a hand in the first week of the month. Notion won't have it if nobody logged it —
  that's what your memory is for. Offer to log it as an event.

## Compose

- **Organise, don't just list.** For each event, the question is "what would stop this happening?"
  Name the blocker and propose the fix.
- **Propose owners, never assign them.** Where something needs a person, suggest one from Members'
  `Skills` (or `Interests` where it's enthusiasm rather than skill) and put it as a question to
  them or to the room. A name in a database is not a commitment, and volunteering someone publicly
  is a good way to lose a volunteer.
- **Draft what wants drafting.** If an event hasn't been announced, offer the announcement — show
  the draft, don't post it (ground rule 4).
- **Build the "needs doing" list** from everything gathered, and keep it to what can actually be
  done this week.
- **Keep the Admin-only material out of it**, exactly as the daily brief does: verification
  backlogs and duplicate-account suspects go to the Admins privately.

## Delivery

Post to the community's group chat **on each connected platform** — Telegram, Discord, or both,
whichever were chosen at onboarding. Each platform's group chat is a separate room (ground rule
11). Chunk to the platform's limit.

## Output

```
🗓️ Week ahead: <date range>

Needs doing this week  (lead with the actionable)
- <action>: by <when> <(owner, if there is one)> · <the blocker, plainly>
- ...

The week
Mon: <event> at <place> · <host> · <n> going · <helpers still short, if any>
Tue: ...

Coming back
- <item>: due <day>

Still needed
- <help request>: needed by <day> — <still looking for someone / a name worth asking>

Notices
- <pinned item worth restating>
- <news expiring <day>>: renew or archive?

Further out
- <the thing that needs starting now to happen later>
```

Drop any empty section. Lead with **Needs doing** so the actionable items are the first thing they
see; the day-by-day, the notices and the further-out items follow.
